# Cocina La Doñita

Sitio estático listo para GitHub Pages. Incluye HTML, estilos, JavaScript, imágenes y tipografías locales. No requiere instalación ni compilación.

## Subir a GitHub

1. Crea un repositorio nuevo, por ejemplo `la-donita`.
2. Descomprime este ZIP.
3. Sube su contenido al repositorio: `index.html`, `style.css`, `actualizacion.css`, `script.js`, la carpeta `assets` y `.nojekyll`. Mantén la carpeta `assets` completa con sus nombres.
4. `index.html` debe quedar en la raíz del repositorio, no dentro de otra carpeta.
5. Ve a Settings > Pages. En Build and deployment selecciona Deploy from a branch, la rama main y la carpeta / (root). Guarda.
6. Cuando GitHub termine de publicar, Pages mostrará el enlace de tu página.

## Editar

- Textos, menús, horarios y precios: `index.html`.
- Diseño: `style.css` y `actualizacion.css` (esta última contiene los ajustes más recientes).
- WhatsApp y menú móvil: `script.js`.
- Imágenes y tipografías: `assets/`.

Puedes abrir `index.html` en tu navegador para revisar la página antes de subirla.

La exportación conserva la versión actual. No incluye la motoneta, fotos adicionales de desayunos/cenas ni el video, porque todavía no se proporcionaron esos archivos.
